# Skill-system agent routing

Load `platform-skill-governance` for any change to canonical skills, their
index, routing, naming, metadata, bridges, or validation. Add another boundary
skill only when the skill-system change alters that boundary's decision
procedure, not merely because the boundary is named in routing text.

Keep canonical skill content under `.agents/skills`; synchronize active bridges
and references, and do not turn skills into copies of repository policy or
architecture documentation.
