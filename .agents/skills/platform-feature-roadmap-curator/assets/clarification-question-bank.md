# Roadmap Clarification Question Bank

Use only the questions needed.

## Intent

1. What are we roadmapping?
2. Why is this being built now?
3. What problem does it solve?
4. Who benefits?

## Scope

1. What is the first useful version?
2. What belongs short-term but not MVP?
3. What is long-term?
4. What is explicitly out of scope?

## Traceability

1. Which user journey does this serve?
2. Which ADRs constrain this?
3. Which modules/screens/services are affected?
4. Which artifacts must be created or updated?

## Delivery

1. What dependencies exist?
2. What risks should change sequencing?
3. What acceptance criteria prove success?
4. Should tickets be generated now or after approval?
