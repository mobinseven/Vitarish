## Route and environment blockers

The current route inventory defines password, email/phone challenge, passkey, session, logout, antiforgery, and account-credential endpoints. It does not define refresh/renewal, account-recovery, or explicit reauthentication routes, so those `AUTH-002` cases cannot be exercised without changing the public contract. The current API composition also has no mapped audit-query endpoint or export endpoint; `IAuditQueryService` and `ISecurityAuditQueryService` are application services only. Those cases remain explicitly unrun rather than being represented by a test-only route. PostgreSQL durability/outage/recovery is now covered by the gated persistence tests; Redis/Data Protection lifecycle cases still require a successful evaluated Main compose startup, which was not achieved because the reused PostgreSQL volume credentials did not match the later compose environment.
