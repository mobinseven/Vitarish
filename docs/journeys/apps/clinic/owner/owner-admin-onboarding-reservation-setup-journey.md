# Admin Onboarding and Reservation Setup (MVP)

## Goal
Enable an admin to configure reservations for first use.

## Trigger
New clinic tenant starts using reservations.

## Steps (MVP)
1. Open Reservation Settings.
2. Set clinic timezone and working days.
3. Set default booking window and cancellation policy.
4. Save and run a setup check.

## Output
Reservation module is marked "Ready".

## Out of scope
Provider schedules, service catalog, and appointment operations.
