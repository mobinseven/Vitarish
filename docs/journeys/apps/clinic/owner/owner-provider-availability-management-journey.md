# Provider Availability Management (MVP)

## Goal
Maintain provider working availability used by booking.

## Trigger
Admin updates provider schedule or exception.

## Steps (MVP)
1. Select provider.
2. Set recurring weekly hours.
3. Add one-off exceptions (leave/blocked time).
4. Publish availability.

## Output
Provider availability calendar is updated.

## Out of scope
Service duration/pricing and patient booking creation.
