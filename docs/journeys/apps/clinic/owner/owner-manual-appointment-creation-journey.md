# Manual Appointment Creation (MVP)

## Goal
Create an appointment on behalf of a patient.

## Trigger
Patient calls/messages clinic for booking.

## Steps (MVP)
1. Find patient.
2. Select appointment type.
3. Select provider + time slot from available options.
4. Confirm booking.

## Output
Reservation is created with status "Confirmed" (or "Pending Approval" per policy).

## Out of scope
Reschedule/cancel and no-show resolution.
