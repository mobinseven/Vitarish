# Edit / Reschedule / Cancel Appointment (MVP)

## Goal
Safely change an existing appointment.

## Trigger
Patient or clinic requests a change.

## Steps (MVP)
1. Open appointment details.
2. Choose action: edit notes, reschedule, or cancel.
3. If reschedule: select new valid slot.
4. If cancel: capture required reason.
5. Save and notify patient.

## Output
Appointment state and audit history are updated.

## Out of scope
Day-of no-show handling.
