# Service / Appointment-Type Setup (MVP)

## Goal
Define bookable appointment types.

## Trigger
Admin adds or edits clinic services.

## Steps (MVP)
1. Create appointment type name.
2. Set duration and buffer.
3. Set eligibility (provider group/location).
4. Activate appointment type.

## Output
Appointment type becomes available to scheduling flows.

## Out of scope
Provider availability edits and manual appointment booking.
