# Clinic Owner Prescription Component-to-Journey Coverage Matrix

Date created: 2026-07-08

## Scope and Source of Truth

- **App:** Clinic Owner
- **Module:** Prescription
- **Capability:** E-prescription owner workflows
- **Accepted capability source of truth:** [`docs/platform/modules/medical/capabilities/prescription/journeys/component-journey-coverage.md`](../../../../../platform/modules/medical/capabilities/prescription/journeys/component-journey-coverage.md)
- **Evidence sources:** Clinic Owner prescription journeys and the platform prescription component coverage matrix.
- **Confidence level:** Medium — this app-level matrix preserves Clinic Owner navigation traceability while avoiding a duplicate lifecycle source of truth.

Prescription lifecycle, template, eligibility, fallback, reconciliation, print, timeline, credential, and reference-admin component coverage is maintained in the platform prescription capability matrix. This app-level matrix maps Clinic Owner journey files to that accepted source so app journeys remain traceable without creating a second prescription state model.
