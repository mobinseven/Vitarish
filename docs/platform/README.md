# Platform Documentation

Status: Active  
Owner: Platform Architecture  
Scope: App-agnostic platform and module documentation  
Last reviewed: 2026-07-08

Platform docs describe reusable module behavior, contracts, decisions, roadmaps, tasks, tests, runbooks, providers, and shared design-system guidance. They must not describe one app's presentation of a module; app-specific usage belongs under `docs/apps/<app>/`.

## Key areas

- [Shared design system](design-system/) for platform-wide reusable design-system decisions and tests.
- [Modules](modules/) for app-agnostic module documentation.
