# Landing Page Integration Plan

## Goal

Integrate the template at `docs/templates/landing-page/` into the Next.js 15 web host as a landing page for unauthenticated users at the root `/` route. All 11 sections, Vitarish branding, localized strings (fa/en).

---

## Phase 0: Dependency Installation

Install `@iconify/react` — the only missing dependency. `motion` (v12) and `react-aria-components` (v1.19) are already in `package.json`.

```bash
pnpm add @iconify/react
```

---

## Phase 1: CSS Integration

**File:** `src/Hosts/Web/src/app/globals.css`

Append after the existing `@custom-variant` line (do not replace existing imports):

1. Brand tokens from `docs/templates/landing-page/brand/tokens.css` (13 lines of CSS custom properties)
2. Font stacks (`--font-sans`, `--font-display`, `--font-mono`)
3. Light/dark oklch surface, muted, border, separator, background, foreground variables from `docs/templates/landing-page/index.css` lines 13-40
4. Loading shimmer animation (`@keyframes loading-shimmer`)
5. `@layer base` typography (body font-family, heading font-family + letter-spacing)
6. `@layer utilities` blueprint classes (`.bp-label`, `.bp-grid`, `.bp-ruler`, etc.)
7. `@layer components` (`.button`, `.navbar`)

**File:** `src/Hosts/Web/src/app/layout.tsx`

Add Google Fonts via `next/font/google`:
- Inter (`--font-sans`)
- Space Grotesk (`--font-display`)
- JetBrains Mono (`--font-mono`)

Apply font CSS variables to `<html>` alongside existing classes.

## Phase 3: Landing Feature Module

### 3a: Brand

**New files:** `src/Hosts/Web/src/features/landing/brand/`
- `metadata.json` — Vitarish name, tagline, description (replacing "Axon Grid")
- `tokens.css` — copy from template (brand CSS custom properties)
- `index.tsx` — `BrandLogotipo`, `BrandIsotipo`, `BrandLogo`, `BrandMark` components with inline SVG fallback

### 3b: Data

**New file:** `src/Hosts/Web/src/features/landing/data/figures.ts`
- Copy `docs/templates/landing-page/data/site.ts`
- Keep `STYLE_BRIEF`, `Figure` type, 8 CDN image URLs
- Keep `prompt` fields for tooltip display

### 3c: Icons

**New files:** `src/Hosts/Web/src/features/landing/icons/`
- `iconify.tsx` — Iconify wrapper with gravity-ui prefix
- `gravity-ui/icons.json` — bundled icon set (~2353 lines)
- `gravity-ui/index.js` — re-exports

### 3d: Sections (12 files)

**New files:** `src/Hosts/Web/src/features/landing/sections/`

Copy all section components from `docs/templates/landing-page/components/sections/`:
- `header.tsx` — Navbar with Login/Sign Up buttons (using `useAuthSession` + `Routes.Login.Index`)
- `hero.tsx` — Hero with CTA buttons
- `trust-strip.tsx` — Company logos bar
- `pillars.tsx` — Four platform pillar cards
- `architecture.tsx` — System architecture diagram
- `metrics.tsx` — Key metrics display
- `code-preview.tsx` — Code snippet tabs
- `feature-rows.tsx` — Three feature deep-dive rows
- `pricing.tsx` — Three pricing tiers
- `final-cta.tsx` — Final call-to-action
- `footer.tsx` — Footer with links
- `theme-toggle.tsx` — Light/dark toggle

**Import path changes per section:**

| Old | New |
|---|---|
| `../../data/site` | `../data/figures` |
| `../../icons/iconify` | `../icons/iconify` |
| `../blueprint` | `@/components/blueprint` |
| `../../brand` | `../brand` |

**Localization:** Add `useLocalizedText()` to every section with user-facing text. Replace all hardcoded strings with `t("landing.section.key")` calls.

**Auth buttons in header.tsx:** Add Login and Sign Up buttons. Login links to `Routes.Login.Index`. Sign Up is a placeholder (`#`).

### 3e: Orchestrator

**New file:** `src/Hosts/Web/src/features/landing/landing-page.tsx`

`"use client"` component composing all 11 sections in order:
```
Header → Hero → TrustStrip → Pillars → Architecture → Metrics → CodePreview → FeatureRows → Pricing → FinalCta → Footer
```

## Phase 5: Root Page Integration

**File:** `src/Hosts/Web/src/app/page.tsx`

Replace current `SessionRedirect` with an auth-gated client component:
- If loading: show minimal loading state
- If authenticated: `router.replace(Routes.Home)`
- If anonymous: render `<LandingPage />`

**Preserved:** `SessionRedirect` and `AuthenticatedRedirectBoundary` remain untouched — used by other routes.

## Verification

1. `pnpm build` succeeds without errors
2. Anonymous visitor to `/` sees full 11-section landing page
3. Authenticated visitor to `/` redirects to `/home`
4. All text uses `t()` — switching fa/en updates all landing page text
5. Farsi renders correctly in RTL mode
6. Login button navigates to `/login`
7. Sign Up button is a placeholder
8. Hash anchors (`#pillars`, `#pricing`) scroll to sections
9. Dark/light theme toggle works
10. Existing dashboard routes unaffected
